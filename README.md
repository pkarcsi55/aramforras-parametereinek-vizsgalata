# Áramforrás paramétereinek vizsgálata

Arduino Nano alapú automatikus mérőeszköz áramforrások terheléses vizsgálatához. A program PWM-vezérelt MOSFET segítségével változtatja a terhelést, és CSV-formátumban rögzíti a feszültség- és áramértékeket.

A mérésből meghatározható az áramforrás elektromotoros ereje, belső ellenállása és számított rövidzárási árama.

[Részletes leírás és kapcsolási rajz](https://pilath.wordpress.com/aramforras-parametereinek-vizsgalata/)
